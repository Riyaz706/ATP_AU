# Phase 1 Capstone Project

This directory contains the Capstone Project for Phase 1 of the Advanced Training Program.

The project is built as a single-page React client application that showcases a catalog of modern technology gadgets.

## Directory Layout

- `Phase1/` (this folder): Root directory of the Capstone project.
- `Phase1/Phase1/` (sub-project): The Vite-powered React application source directory containing component structures and asset files.

## Running the Application

To install dependencies and start the local development server:

1. Navigate to the nested project directory:
   ```bash
   cd Phase1/Phase1
   ```

2. Install the package dependencies:
   ```bash
   npm install
   ```

3. Launch the development server:
   ```bash
   npm run dev
   ```
