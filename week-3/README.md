# Week 3 — Node.js Backend Development

Building RESTful APIs with Node.js and Express — first with in-memory storage, then with MongoDB.

## 📂 Projects

### 1. BackendWithLocalMemory
A REST API that stores data in memory (no database).

```bash
cd BackendWithLocalMemory
npm install
node server.js
```

### 2. BackendWithDataBase
A REST API backed by MongoDB using Mongoose ODM.

```bash
cd BackendWtihDataBase
npm install
# Add your MongoDB URI to environment or server.js
node server.js
```

## 🛠️ Tech Stack
- Node.js
- Express.js
- MongoDB + Mongoose (for DB project)

## 🔗 API Testing
Use the included `request.http` files with the REST Client VS Code extension.
