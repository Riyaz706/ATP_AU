# Frontend Fundamentals

Practical exercises in client-side development covering semantic HTML structures, advanced CSS layout methods (Flexbox, Grid), and vanilla JavaScript DOM API operations.

## Directory Structure

| Folder | Description |
|--------|-------------|
| `html/` | Basic HTML structure, tables, forms, and validation rules. |
| `css/` | CSS selectors, typography, styling, responsive breakpoints, Flexbox, and Grid configurations. |
| `js/` | JavaScript DOM manipulation, event listeners, dynamic style toggling, and input processing. |
| `assignment-1/` | Basic layouts exercise using standard HTML elements. |
| `assignment-2/` | Intermediate CSS styling assignments. |
| `assignment-2a/` | Extended CSS features exercise, including media queries for mobile-responsive support. |
| `assignment-3(Travel Website)/` | Responsive travel booking homepage static UI implementation. |
| `Assets/` | Shared graphic resources, images, and brand materials used across projects. |

## Running the Code

These are client-only static pages. They do not require an active server runtime.

1. Double-click any `.html` file (e.g. `index.html` inside `assignment-3(Travel Website)`) to open it directly in a web browser.
2. Alternatively, open this folder in VS Code and use the Live Server extension to run a local hot-reloading server.
