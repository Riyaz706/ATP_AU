# Travel Website Landing Page

A mobile-responsive travel reservation landing page mockup built with semantic HTML5 and vanilla CSS3.

## Features

- Flexbox navigation menu with hover transitions.
- Responsive hero presentation section showcasing travel destinations.
- Travel categories grid utilizing responsive CSS breakpoints.
- Interactive form mockups for searching flights and booking dates.
- Clean typography and unified colors without dependencies on CSS frameworks.

## Project Structure

- `index.html`: Structure definition using semantic elements (`header`, `main`, `section`, `footer`).
- `style.css`: Layout stylesheet holding styles for media containers, grid properties, and mobile display overrides.
- `../Assets/`: Remote/shared asset elements loaded onto standard page templates.

## Run Locally

Open the `index.html` file directly in any modern web browser or start a local file server (like Live Server in VS Code) to review the layout, responsiveness, and interaction points.
