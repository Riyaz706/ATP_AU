# React Product Catalog Routing Demo

This directory contains a product catalog browser routing project.

The source and routing configurations are located in the [vite-project](file:///Users/mdriyaz/.gemini/antigravity/scratch/ATP_AU/week-8/react-demo3/vite-project) subdirectory.

## Quick Start

1. Navigate to the nested project directory:
   ```bash
   cd vite-project
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

Refer to the nested documentation inside the [vite-project folder](file:///Users/mdriyaz/.gemini/antigravity/scratch/ATP_AU/week-8/react-demo3/vite-project/README.md) for detailed descriptions of the components and routes.
