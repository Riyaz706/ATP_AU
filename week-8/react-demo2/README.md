# React Nested Routing Demo

This directory contains a nested routing demonstration project built using React Router.

The actual project source and configuration are located in the [my-project](file:///Users/mdriyaz/.gemini/antigravity/scratch/ATP_AU/week-8/react-demo2/my-project) subdirectory.

## Quick Start

1. Navigate to the nested project directory:
   ```bash
   cd my-project
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

Refer to the nested documentation inside the [my-project folder](file:///Users/mdriyaz/.gemini/antigravity/scratch/ATP_AU/week-8/react-demo2/my-project/README.md) for detailed routes specifications and features.
