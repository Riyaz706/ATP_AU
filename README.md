# ATP_AU — Advanced Training Program

A collection of weekly assignments and projects completed as part of the Advanced Training Program (ATP).

## 📁 Structure

| Folder | Description |
|--------|-------------|
| `week-1/` | JavaScript fundamentals — functions, arrays, student performance |
| `week-2/` | Collections, shallow copy, TODO app |
| `week-3/` | Node.js backend — REST APIs with local memory & MongoDB |
| `week-6/` | HTML, CSS, JavaScript — assignments & travel website |
| `week-7/` | React projects — Country Explorer, Product Manager, Task Manager |
| `week-8/` | React demos & User REST API |
| `Phase1/` | Phase 1 capstone project |
| `Project/` | Full-stack project (frontend + backend) |

## 🛠️ Tech Stack

- **Week 1–2:** Vanilla JavaScript (Node.js)
- **Week 3:** Node.js, Express, MongoDB (Mongoose)
- **Week 6:** HTML5, CSS3, JavaScript
- **Week 7–8:** React, React Router, REST APIs
- **Project:** Full-stack (React + Node.js + Express + MongoDB)

## 🚀 Getting Started

Each sub-project has its own `README.md` with setup instructions. Navigate into any project folder and follow the steps there.
